# 群复读机

连着**两个人**发同样的话，机器人跟着复读一句。实现全在 `src/qq_rss_bot/repeat.py`。

用户 2026-10-20 定的规则：**第 2 个人**发出来才跟。这样机器人不会自己起头，
只在群里真的开始复读时才加入。

```
A: 今天好累啊
B: 今天好累啊        ← 第 2 个人
🤖: 今天好累啊        ← 机器人跟一句
C: 今天好累啊        ← 不跟了（跟过一次就清了状态）
```

## 触发条件：五条全中才跟

1. 群在 `REPEAT_GROUPS` 里
2. 这一条和**上一条**归一化之后完全相同
3. 但**不是同一个人**发的 —— 一个人连发两遍不算复读
4. 这一句**还没被跟过**（跟过就不再跟，直到群里出现别的文本）
5. 距上次复读 ≥ `REPEAT_GAP_SEC`（默认 20 秒）

第 2 条里的「归一化」是 `repeat.normalize()`：剥掉 @、把连续空白压成一个空格。
**两个人 @ 了不同的人、说了同一句话，群里看起来就是在复读**，所以必须剥。
两种 @ 形态都要认：`<@OPENID>`（**指令面板按钮补的就是这种**）和 `@显示名`（手工 @）。

## 不跟的东西

- 空消息 / 纯空白
- 超过 `REPEAT_MAX_LEN`（默认 200）的长文 —— 复读起来像刷屏
- 以 `/` 开头的指令（跟着复读一条指令很怪）
- **预览已经处理过的**：分享的 bilibili / YouTube 链接，机器人已经回过卡片了，
  再复读一遍很傻。由 `_maybe_repeat(skip=...)` 传进来。

⚠️ 但 `skip=True` 的**仍然要喂给 `consider()`** —— 它要把状态里的「上一条」清掉，
不然下一条正常消息会拿更早的那条当「上一条」，复读判定就错位了。

## ⚠️ 防自激循环靠第 4 条，别去掉

机器人自己发的消息**有可能被平台推回来**。推回来的话：

    某人: X  →  机器人复读 X  →  这条又回来  →  又看见「另一个人」发了 X  →  再复读 …

第 4 条（`Repeater._repeated`）在这里是**唯一**的刹车：同一句跟过一次就不再跟，
所以最坏情况也只多一句，不会无限循环。

⚠️ **测这条的时候必须把冷却关掉**（`gap_sec=0`）。不关的话冷却会先一步挡住，
于是刹车坏掉了也测不出来 —— 这是写 smoke 时用变异测试发现的，第一版就漏了。

## 发送形态：被动回复，不是主动消息

走 `_make_repliers` 的 `reply`（**被动回复**，带 `msg_id`）：

- **不占主动消息配额**，也不需要群里开「机器人主动在群聊内发言」
- 代价：客户端会把它渲染成**引用回复**，而不是一条光秃秃的复读

要改成普通消息就换 `self.sender.send_text`（走配额令牌桶）。
⚠️ 换之前注意：`_maybe_repeat` 里**新建**了一个 `_make_repliers`，`msg_seq`
从 1 开始。这只有在 `skip=False`（没有任何预览回过这条消息）时才安全 ——
否则会和预览撞 seq，后发的那条被**静默丢弃**。所以**别在 skip=True 的分支里发东西**。

发送失败**只记 WARNING、不往上抛** —— 它是个锦上添花的群功能，而这条路上
还跑着预览和指令，不能因为复读发不出去就影响它们。

## 状态只在内存里

复读是转瞬即逝的群行为，重启后忘掉上一条完全没问题。落库还要考虑清理，不值当。
代价：重启后群里正在复读的那一句要重新攒够两个人。

## 配置

| 变量 | 默认 | 说明 |
|---|---|---|
| `REPEAT_ENABLED` | `true` | |
| `REPEAT_GROUPS` | 空 | **空 = 整个功能关闭** |
| `REPEAT_MAX_LEN` | `200` | 超过就不跟 |
| `REPEAT_GAP_SEC` | `20` | 同一个群两次复读的最小间隔 |

⚠️ **先只填测试群。** 这个功能和别的都不一样：**每条群消息都可能触发**，
不是定时任务 —— 频率合不合适要真跑过才知道。

## 踩过的坑

- **冷却判断别写成 `.get(group, 0.0)`**。那等于拿 `now` 和 0 比：生产里
  `time.monotonic()` 起点很大所以侥幸能过，但换个时钟（测试里从 0 开始）
  就变成「距上次复读不到 N 秒」，**第一次复读永远不触发**。
  正确写法是 `.get(group)` 拿到 `None` 就直接放行。
- **冷却会掩盖刹车**（见上）。
- **源码钉子要剥掉 docstring 再查**。`_maybe_repeat` 的说明里正好提到
  `self.sender.send_text` 这条替代方案，不剥的话「走的是被动回复」那条检查
  会把注释当成实现来判，永远为假。
