# 角色→声优的关联按 `character_id`，不按名字

imas-db 的两个页面（生日日历、声优一览）用**同一个** `data-character-id` 标识角色，
但两边的显示名写法不一致：生日表写「エミリー・スチュアート」，声优一览写「エミリー」。
按名字匹配只能覆盖 254/382，而且**失败是静默的** —— 漏标的角色会被当成「没有声优」，
从日志上看和真的未付声一模一样，2026-10-21 就是靠人工指出「エミリー 的 CV 是郁原ゆう」
才发现的。按 id 关联是精确的，代价是抓取脚本要多存一个字段。

## 考虑过的选项

- **按名字匹配**：零成本，但源数据里有三种写法会各错一批 —— 截断（`エミリー`）、
  合并（`双海亜美/真美`）、品牌前缀（`ゼノグラシア 双海亜美`）。
- **手工维护 382 行映射表**：不会错，但每上新角色就要手工补，一定会过期。

## 后果

生日表的数据格式要加 `character_id`（当前只存了名字和品牌）。
